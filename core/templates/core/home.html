An open catalog for research engineering.

OSPREY is a searchable commons for open-source research engineering projects such as instruments, hardware designs, firmware, protocols, and the software tools that make research possible but rarely get published anywhere. Publish an open source project here, get a citable DOI, and give the next researcher a starting point.

This system is in a beta testing phase at the moment. Browse the projects or read more about OSPREY.
