About OSPREY

OSPREY is a public-benefit research engineering commons. It is a curation, credit, and lineage layer that sits on top of repositories like GitHub, Codeberg, and Zenodo, rather than a primary file host.

This site is a demo. It carries a small body of pre-loaded projects from the WHOI pilot. Anything OSPREY stores can be exported as plain JSON via /api/v1/export/.

Source-of-truth planning documents live in the planning/ directory of the repository.
