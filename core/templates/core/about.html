About OSPREY

OSPREY (Open Science Platform for Research and Engineering Yields) is a public-benefit commons for open research engineering.

What this site does

OSPREY catalogs open source research engineering projects (hardware, firmware, protocols, datasets, analysis pipelines) with enough metadata that other researchers can actually find and reuse them. Each project gets a citable record (DOI), a contributor list keyed to ORCID iDs, and a lineage graph that links forks and adaptations back to the original.

Why I'm building it

Useful research engineering work often goes uncredited and unfindable. Two graduate students in different labs can spend weeks building the same custom instrument and never know about each other; the work then disappears into a single sentence in a paper. OSPREY is an attempt to make that work easier to share, easier to find, and worth the effort to document.

Status

This site is an early demo. Some pieces work, some are placeholder, and the data model is still moving. If you have a project you'd be willing to list, or feedback on what's missing, I'd appreciate hearing it.

Who runs it

OSPREY is run by Jonathan A Pfeifer through pHalkon Industries LLC as a public-benefit project. The early pilot community is oceanographic engineering, anchored at the Woods Hole Oceanographic Institution.

Contact

Reach out through GitHub or by email if you'd like to help build OSPREY, list a project, or talk about how it might fit your lab.
