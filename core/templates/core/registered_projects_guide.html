How registering a Zenodo record works

There are different ways to get a project onto OSPREY. There is the standard native OSPREY project where OSPREY takes user uploaded files and publishes them to Zenodo, mints the DOI, and looks after the record.

If the work is already on Zenodo, or a creator wants to maintain full control over the Zenodo record for a project, you can register the record on OSPREY instead. OSPREY will read the information from the Zenodo record and populate the OSPREY project with that information.

A registered project has most of the same benefits as a native OSPREY project. They are both listed in the database, both have features like tracking lineage, providing wikis, etc. The main difference is who looks after the Zenodo record and what metadata goes into the Zenodo record.

Registering a record

Your OSPREY-associated ORCID iD must be listed as a creator on the Zenodo record. This serves as a check to ensure that you are authorized to list the project on OSPREY.

OSPREY will read the Zenodo record and autopopulate the relevant data fields.

Coauthors on the record get a credit row on OSPREY. Coauthors on registered projects with OSPREY accounts will receive a notification to accept a project credit, the same as a native OSPREY project.

A note on licenses. Every project on OSPREY has to have an open license. And the Zenodo record needs to have an open license that OSPREY accepts. If OSPREY finds a non-open license, or a non-standard license, registration will fail. If you feel a specific license should be supported that isn't, you can submit a request in the Suggestion Box and staff will review the request.

How to update Zenodo information on the OSPREY project

The title, authors, license, files and versions come from the record. Changes to these must happen on Zenodo, then you can hit Refresh from Zenodo on the OSPREY project's edit page. An automatic refresh also runs occasionally (typically once per week or so) by itself depending on server load.

The OSPREY community on Zenodo

There is an OSPREY community on Zenodo that native OSPREY projects automatically get added to. If you are registering a project and also want it listed in the Zenodo community, you can optionally add it to that community. On your Zenodo record, choose Submit to community and pick OSPREY. OSPREY should accept Zenodo records to the community within about ten minutes if they belong to a registered project.
