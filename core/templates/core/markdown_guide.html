Images

OSPREY does not host project media. Link to images already hosted somewhere durable (your GitHub repo, Zenodo, lab site). The Markdown syntax is the same as a link, with a leading exclamation point: 

![Alt text](https://example.org/img/diagram.png)

The GitHub image gotcha

A common slip is to paste the regular GitHub web URL for an image, which renders the GitHub viewer page, not the image itself: 

![Alt text](https://github.com/username/repository/blob/master/img/octocat.png)

That does not render. Use one of these instead.

Append ?raw=true:

![Alt text](https://github.com/username/repository/blob/master/img/octocat.png?raw=true)

Or use the raw.githubusercontent.com host:

![Alt text](https://raw.githubusercontent.com/username/repository/master/img/octocat.png)

Same trick works for diagrams committed to your repo. If the image moves, the link breaks; that is the tradeoff for not hosting media in OSPREY.

What is allowed

OSPREY's renderer allows the standard Markdown set plus external http(s) image URLs. Raw HTML is stripped. If something you expected to render did not, that is probably why.
