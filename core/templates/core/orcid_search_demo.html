Throwaway demo of the contributor ORCID-lookup idea on the project submission form. Type a name, press Search, and OSPREY hits ORCID's public expanded-search API once. Submit-on-button (rather than typeahead) keeps us well clear of the 24 requests/second rate limit on the public API. If this lookup makes it into the real submission form, the button stays.
